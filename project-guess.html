QUÊTE : LE JUSTE NOMBRE

📜 DESCRIPTION DE LA MISSION

Développement d'un jeu classique "Guess the Number" en deux versions : JavaScript (web) et Python (console). L'utilisateur doit deviner un nombre aléatoire, le programme indiquant si le nombre cherché est plus haut ou plus bas. Le projet met en avant la logique algorithmique et la gestion des entrées utilisateur.

📑 CAHIER DES CHARGES

Le cahier des charges imposait deux implémentations du même jeu dans deux langages différents. L'objectif était de comparer les approches web (JavaScript) et console (Python) pour un même problème algorithmique.
